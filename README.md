# 💰 Banking System Project

This is a **Java-based Banking System** developed using **JDBC and MySQL**.  
The project simulates real-world banking operations like account creation, transactions, and balance management.

## 📌 Features

- Account Creation  
- Deposit Money  
- Withdraw Money  
- Balance Check  
- User Login System  
- Transaction History  

## 🛠️ Tech Stack

- Java  
- JDBC  
- MySQL  
- JavaFX (UI)  

## 📂 Project Structure
src/
├── Main.java
├── LoginUI.java
├── DashboardUI.java
├── BankService.java
├── DBConnection.java
├── Transaction.java
├── User.java
└── DAO Classes

## ▶️ How to Run

1. Clone the repository: https://github.com/aspakahmed/Banking-System.git

2. Open in IDE (IntelliJ / Eclipse)

3. Setup MySQL Database

4. Run Main.java
